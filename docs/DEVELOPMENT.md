# Для разработчиков

## Как это устроено

```
Страница Steam ──► content.js ──(сообщение)──► background.js ──► Plati API
 (читает название           рисует панель        (service worker)   GGSel API
  и цену игры)              в Shadow DOM                            Steam API, курсы ЦБ
```

- **`src/content/content.js`** — работает прямо на странице Steam: читает название и цену игры, рисует панель. Панель живёт в **Shadow DOM** — изолированном куске страницы, куда не проникают стили Steam (и наши не ломают Steam).
- **`src/background.js`** — фоновый скрипт. Страница Steam не может ходить на чужие сайты (это запрещает **CORS** — защита браузера от запросов между сайтами), а расширение может: разрешённые сайты перечислены в `host_permissions` в `manifest.json`.
- **`src/lib/`** — вся логика:
  - `sources/plati.js`, `sources/ggsel.js` — поиск на площадках. У Plati открытый API, у GGSel — тот же внутренний API, через который работает поиск на их сайте.
  - `match.js` — проверяет, что лот про ту же игру («Hollow Knight: Silksong» не попадёт в «Hollow Knight»).
  - `classify.js` — что продаётся: ключ, гифт, аккаунт, аренда или другая платформа; регион.
  - `offers.js` — собирает всё вместе: фильтры, валюты, проверенные продавцы, лучшая цена.
  - `watchlist.js` — список желаемого, проверка цен по расписанию, уведомления.
  - `config.js` — настройки по умолчанию и их миграция между версиями.
- **`src/popup/`** — окно по клику на иконку. **`src/options/`** — настройки.
- **`src/content/wishlist-sync.js`** — если пользователь вошёл в Steam, раз в 30 минут забирает номера игр из списка желаемого (тот же запрос делает сам Steam). На страницах входа и оплаты не запускается.

Сборщика нет: обычный JavaScript, браузер грузит файлы как есть. Типы проверяются через JSDoc и `tsc`.

## Команды

```bash
npm i                              # typescript, eslint, playwright (только для проверок)
npx playwright install chromium    # браузер для e2e-тестов
npm run typecheck                  # проверка типов (tsc)
npm run lint                       # eslint
npm test                           # юнит-тесты + e2e в настоящем Chromium
npm run build                      # собрать dist/deshevle.zip
```

- `tests/unit.mjs` — тесты логики на **реальных ответах Plati и GGSel**, сохранённых в `tests/fixtures/`.
- `tests/e2e.mjs` — грузит расширение в Chromium, открывает копию страницы Steam, подменяет сеть, проверяет панель, попап, уведомления и настройки, делает скриншоты в `tests/screenshots/`.

Сборка (`scripts/build-zip.mjs`) работает без внешних пакетов — нужен только Node.js.

## Как выпустить новую версию

1. Подними версию в `manifest.json` (`"version": "1.0.1"`) и в `package.json`.
2. `npm run typecheck && npm run lint && npm test`
3. `npm run build` — появятся `dist/deshevle.zip` и `dist/deshevle-v1.0.1.zip`.
4. Закоммить и запушь.
5. На GitHub: **Releases → Draft a new release** → тег `v1.0.1` → описание изменений → прикрепи **`dist/deshevle.zip`** (именно с этим именем — на него ведёт кнопка «Скачать» в README) → **Publish release**.

Ссылка `https://github.com/Okbitsnok/steam-deshevle/releases/latest/download/deshevle.zip` всегда отдаёт архив из последнего релиза.

## Что может сломаться и где чинить

| Симптом | Где смотреть |
|---|---|
| Панель не появилась | Steam поменял вёрстку → `readGame()` и место вставки в `src/content/content.js` |
| GGSel «ошибка» в подвале панели | GGSel поменял внутренний API → `src/lib/sources/ggsel.js` |
| Попала чужая игра / пропала нужная | `src/lib/match.js` (список `NOISE`) |
| Ключ определился как гифт и наоборот | `src/lib/classify.js` |

Ошибки фонового скрипта: `chrome://extensions` → «Дешевле» → «Service worker» → Console.

## Ручная проверка перед релизом

Автотесты гоняют расширение на копии страницы Steam с сохранёнными ответами площадок. Перед релизом стоит пройтись руками по живым сайтам:

- [ ] Detroit: Become Human (app/1222140) — панель, цены, у GGSel и Plati зелёные точки в подвале
- [ ] Hollow Knight (app/367520) — нет лотов Silksong
- [ ] Бесплатная игра (Dota 2, app/570) — панели нет
- [ ] Вкладки «Ключи», «Гифты», «Аккаунты», «Пополнение»; «лучшая цена» — не аккаунт
- [ ] «Следить за ценой» → игра в попапе → ↻ → «Готово: проверил N игр»
- [ ] Настройки: подсказки «?», выключение площадок и аккаунтов применяется на странице игры
- [ ] Установка из `dist/deshevle.zip` по инструкции из README в чистом профиле браузера
